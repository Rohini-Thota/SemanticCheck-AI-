Optional embedding files:
- Word2Vec: place a gensim Word2Vec .model or .kv file at embeddings/word2vec.model.
  You can also train a small Word2Vec model from the two documents being compared (see notes below).
- GloVe: place a GloVe text file at embeddings/glove.6B.100d.txt.
  Download from https://nlp.stanford.edu/projects/glove/ (the 6B archive contains 50d/100d/200d/300d vectors).
- These pretrained embedding files are large and are not bundled in the project.
